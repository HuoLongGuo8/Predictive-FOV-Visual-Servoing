# Predictive-FOV-Visual-Servoing
面向视场约束下无人机目标跟踪的预测视觉伺服制导
## 项目简介

本项目面向无人机运动目标视觉跟踪与制导任务，研究目标图像预测和视场约束条件下的视觉伺服制导方法。

在实际视觉伺服过程中，图像采集、目标检测与跟踪处理会引入一定时延，同时目标机动、短时遮挡以及观测噪声可能导致目标图像位置出现抖动、漂移或短时中断。当目标接近图像边界时，传统视觉伺服方法还可能出现跟踪稳定性下降甚至目标脱离视场的问题。

针对上述问题，本项目主要包括以下内容：

- 基于目标检测框中心构造图像视觉特征；
- 建立目标图像状态预测模型；
- 利用预测结果补偿视觉处理时延；
- 引入视场约束，降低目标脱离图像范围的风险；
- 构建面向运动目标跟踪的预测视觉伺服制导方法。

本方法直接利用图像平面中的目标特征进行反馈，不依赖目标精确深度信息和完整三维相对位姿重建。
